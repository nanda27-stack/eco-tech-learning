Cara melihat:
1. Ekstrak ZIP.
2. Buka folder eco_tech_learning.
3. Klik dua kali index.html.
4. Pastikan perangkat terhubung internet agar Tailwind CSS CDN termuat.

Cara memakai di Google Sites:
Google Sites tidak mengimpor folder HTML menjadi halaman native secara langsung.
Untuk menampilkan website ini, unggah file ke layanan hosting statis (misalnya GitHub Pages),
lalu di Google Sites gunakan Sisipkan > Sematkan > URL.
Alternatifnya, salin konten dan bangun ulang tiap halaman memakai elemen Google Sites.
